# 🍽️ R V Cafe - Restaurant Management System

A full-stack Restaurant Management System developed using PHP, MySQL, Bootstrap, HTML, CSS, and JavaScript.

## 📌 Features

### Customer Side

* Home Page
* Dynamic Food Menu
* Food Image Gallery
* Online Table Booking
* Shopping Cart
* WhatsApp Food Ordering
* Contact Page

### Admin Side

* Secure Admin Login
* Dashboard with Statistics
* Menu Management (Add / Delete Food Items)
* Food Image Upload
* Booking Management
* Order Management
* Revenue Tracking

## 🛠️ Technologies Used

* PHP
* MySQL
* Bootstrap 5
* HTML5
* CSS3
* JavaScript
* XAMPP

## ⚙️ Installation

1. Clone the repository

git clone https://github.com/ajaythakur3/R-V-Cafe-Restaurant-Management-System.git

2. Move project to XAMPP htdocs folder

3. Import database/restaurant.sql into phpMyAdmin

4. Start Apache and MySQL

5. Open:

http://localhost/Restaurant_booking_system
